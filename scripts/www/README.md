# 一轮进度 MVP

一个无需安装开发环境的静态 Web App，用于追踪高考一轮复习进度。

## 使用方式

直接双击 `index.html`，或使用任意静态文件服务器打开本目录。

## 当前功能

- 首页今日任务台，可直接从五科现有目录选择梳理、刷题或复盘任务
- 今日任务完成进度、任务勾选与按日期独立保存
- 支持安排今天、明天或任意未来日期的任务，到期自动进入今日清单
- 逾期任务支持移到今天、改期或放弃
- 完成任务时评价“不熟、一般、熟练”并记录可选错因备注
- 根据掌握程度自动在 1、3、7 天后安排复盘任务
- 每项任务首次完成后同步更新对应科目的复习进度，并输出一条跨科复习日志
- 数学、生物、化学、语文与物理进度总览
- 数学 12 章、40 个复习模块
- 数学、生物、化学聚焦思维导图
- 生物 6 个内容分类、28 个章节，章节直接记录状态
- 化学 6 个知识大类、16 章、57 个核心模块
- 物理 6 个知识大类、19 章，章节直接记录状态
- 未开始、已梳理、已刷题、已复盘四档状态
- 本地保存每个模块的复习状态
- 自动记录日期、时间、状态变化和可选复习备注
- 按日期倒序展示跨科复习日志
- 生物按“教材 -> 章节”思维导图浏览，28 个章节直接记录状态
- 语文内置 73 篇古诗文，按一至三轮独立记录待背、在背、已背和已默写状态
- 手机端响应式布局，适配 APK WebView、安全区、矮屏与横屏画布

## 当前范围

此版本实现知识树和三级复习进度，不包含错题、学习心得、数据库、AI 或 PWA。

## 文件说明

- `index.html`：各科复习进度总览
- `math.html`：数学复习入口
- `biology.html`：生物复习入口
- `chemistry.html`：化学复习入口
- `physics.html`：物理复习入口
- `chinese.html`：语文古诗文背诵入口
- `css/styles.css`：全局样式
- `js/knowledge-tree.js`：数学知识树数据
- `js/biology-tree.js`：生物教材与章节数据
- `js/chemistry-tree.js`：化学知识大类、章节与模块数据
- `js/physics-tree.js`：物理知识大类与章节数据
- `js/subject-map-app.js`：生物、化学与物理共用思维导图逻辑
- `js/chinese-tree.js`：古诗文背诵篇目数据
- `js/chinese-app.js`：背诵轮次与进度逻辑
- `js/app.js`：Hash 路由与页面渲染
